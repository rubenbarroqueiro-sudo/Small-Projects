World Wide Web

WWW · A Rede de Alcance Mundial

Um sistema global de documentos interligados executados na Internet, criado por Tim Berners-Lee em 1991 — a fundação de toda a web moderna.

📌 Secção 1

O que é a World Wide Web#

Ficha Técnica
Nome completoWorld Wide Web
AbreviaturaWWW / Web
CriadorTim Berners-Lee
Ano1989–1991
LocalCERN, Suíça
Tecnologia baseHTTP, HTML, URI
Publicado em6 Agosto 1991

A World Wide Web — que significa "rede de alcance mundial" em inglês, também conhecida como Web e WWW — é um sistema de documentos que são interligados e executados na Internet. Os documentos podem estar na forma de vídeos, sons, hipertextos e imagens.

Para visualizar a informação, pode-se usar um programa de computador chamado browser para descarregar informações (chamadas "documentos" ou "páginas") de servidores web (ou "sítios") e mostrá-los no ecrã do utilizador.

O utilizador pode então seguir as ligações na página para outros documentos ou mesmo enviar informações de volta para o servidor para interagir com ele. O ato de seguir ligações é normalmente chamado de "navegar" ou "surfar" na Web.

💡

Nota importante: A Web (substantivo próprio) é diferente de web (substantivo comum), já que a Web engloba toda a Internet. Outras webs existem em redes privadas (restritas) que podem não fazer parte da Internet.

🕰 Secção 2

História e Origens#

As ideias por trás da Web podem ser identificadas ainda em 1980, na CERN (Suíça), quando Tim Berners-Lee construiu o ENQUIRE. Ainda que diferente da Web atual, o projeto continha algumas das mesmas ideias primordiais, e também algumas ideias da web semântica. O objetivo original era tornar mais fácil a partilha de documentos de pesquisas entre colegas.

O conceito crucial do hipertexto originou-se em projetos da década de 1960, como o projeto Xanadu e o NLS. A ideia revolucionária de Tim foi unir o hipertexto e a Internet. No seu livro Weaving The Web, ele explica que sugeriu repetidamente o casamento das tecnologias para membros de ambas as comunidades, mas como ninguém implementou a sua ideia, decidiu implementá-la por conta própria.

1980 — CERN, Suíça
Tim Berners-Lee constrói o ENQUIRE, precursor da Web, com o objetivo de facilitar a partilha de documentos de investigação.
Março de 1989
Berners-Lee escreve uma proposta de gestão de informação, referenciando o ENQUIRE e descrevendo um sistema mais elaborado.
Final de 1990
Com a ajuda de Robert Cailliau, publica uma proposta formal para a World Wide Web. Um computador NeXTcube é usado como primeiro servidor web e para escrever o primeiro navegador, o WorldWideWeb.
6 de Agosto de 1991
Berners-Lee posta um resumo no grupo de notícias alt.hypertext. Esta data marca a estreia da Web como serviço publicado na Internet.

No final de 1990, Berners-Lee já tinha construído todas as ferramentas necessárias para o sistema: o navegador, o servidor e as primeiras páginas web, que descreviam o próprio projeto. No processo, desenvolveu um sistema de identificação global e único de recursos — o Uniform Resource Identifier (URI).

⚙️ Secção 3

Como Funciona#

Visualizar uma página web ou outro recurso disponibilizado normalmente inicia ao digitar uma URL no browser ou seguindo (acedendo) uma ligação. O processo envolve várias etapas técnicas que acontecem em frações de segundo.

1

Resolução DNS

A parte da URL referente ao servidor web é separada e transformada num endereço IP através de uma base de dados da Internet chamada Domain Name System (DNS).

2

Ligação TCP/IP

O browser estabelece uma conexão TCP/IP com o servidor web localizado no endereço IP retornado pelo DNS.

3

Pedido HTTP

O browser envia um pedido HTTP ao servidor, que responde com o conteúdo da página (HTML, CSS, imagens, etc.).

4

Renderização

O browser interpreta e renderiza o conteúdo recebido, apresentando a página ao utilizador de forma visual e interativa.

💡 Secção 4

Conceitos Fundamentais#

A Web assenta em três tecnologias fundamentais desenvolvidas por Tim Berners-Lee: o URI/URL (identificador único de recursos), o HTTP (protocolo de transferência de hipertexto) e o HTML (linguagem de marcação de hipertexto). Juntas, estas tecnologias formam a infraestrutura que permite a qualquer pessoa publicar e aceder a conteúdo na Internet.

O hipertexto — o conceito central da Web — permite que documentos contenham ligações para outros documentos, criando uma teia interconectada de informação. Esta ideia, inicialmente proposta nos anos 1960, ganhou escala global quando Berners-Lee a uniu ao poder da Internet.

🔗

A Web não é a mesma coisa que a Internet. A Internet é a infraestrutura de rede física global; a Web é um dos serviços que corre sobre ela, tal como o email ou o FTP.
